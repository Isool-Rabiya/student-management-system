# Student Management System

A simple and efficient Student Management System built using Spring Boot, Java, and JavaScript.

## 🚀 Features
- Add new students
- View all students
- Edit student details
- Delete students
- REST API + Frontend (HTML/JS)

## 🛠️ Tech Stack
- Java
- Spring Boot
- MySQL / H2
- Maven
- HTML, CSS, JavaScript

## 🔗 Live Project
This project is built by Isool Rabiya

## How to Run
1. Clone the repo
2. Run `mvn spring-boot:run`
3. Open http://localhost:8080
